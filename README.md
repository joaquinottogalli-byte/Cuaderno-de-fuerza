# GymNotes

App web para registrar pesos, series y repeticiones en el gimnasio.

- `index.html`: la app (HTML, CSS y JavaScript en un solo archivo).
- `manifest.webmanifest`: nombre, ícono y colores para instalarla en el teléfono.
- `sw.js`: service worker, permite abrirla sin conexión.
- `icono-*.png`: íconos.

Los datos se guardan en el navegador de cada dispositivo (localStorage).
Desde la pestaña Historial se puede descargar y cargar una copia de seguridad.
